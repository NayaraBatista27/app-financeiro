# 💰 App Financeiro

Aplicativo de finanças pessoais desenvolvido com **React Native**, **Expo** e **JavaScript**, com o objetivo de facilitar o controle de entradas e despesas mensais.

## ✨ Funcionalidades

- 📊 Resumo financeiro com visão das finanças pessoais.
- 💵 Cadastro e organização de entradas.
- 🧾 Controle de despesas fixas, variáveis e parceladas.
- 📅 Navegação entre meses e anos.
- ✅ Acompanhamento de despesas pagas e pendentes.
- 📈 Gráficos para acompanhar os gastos mensais.
- 🔐 Autenticação de usuários com Firebase.

## 🛠️ Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- Firebase Authentication
- Cloud Firestore
- AsyncStorage
- React Navigation
